# Privacy Policy for Debug Visor

Last updated: April 21, 2026

Debug Visor does not collect, sell, or share personal information.

## What Debug Visor Stores

Debug Visor stores the following settings locally in your browser using Chrome extension storage:

- Whether the overlay is enabled
- The selected overlay color
- The selected overlay opacity

These settings are used only to remember your preferences.

## What Debug Visor Does

When you click the extension, Debug Visor can apply a visual overlay to the current tab so you can inspect page backgrounds more easily.

## What Debug Visor Does Not Do

- It does not send data to any external server.
- It does not collect browsing history for analytics or advertising.
- It does not sell or share user data with third parties.
- It does not use trackers, cookies, or remote code.
- It does not read or transmit passwords, payment data, or personal messages.

## Changes to This Policy

If Debug Visor's data practices change, this policy will be updated before those changes are released.
